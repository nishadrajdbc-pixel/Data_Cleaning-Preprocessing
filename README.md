🧹 Titanic Data Cleaning & Preprocessing

📌 Overview

This project focuses on cleaning and preparing the Titanic dataset for Machine Learning.
The goal is to transform raw, messy data into a model-ready dataset using proper preprocessing techniques.

🛠 Tech Stack

Python

Pandas

NumPy

Matplotlib

Seaborn

Scikit-learn

🔍 Preprocessing Steps

✔ Explored dataset structure and missing values

✔ Handled missing data (median for Age, mode for Embarked, dropped Cabin)

✔ Encoded categorical features (Sex, Embarked)

✔ Applied feature scaling (Standardization)

✔ Detected outliers using boxplots

✔ Reduced skewness in Fare using log transformation

📊 Key Insights

Fare distribution is highly right-skewed.

Missing values must be handled before modeling.

Encoding and scaling are essential for ML algorithms.

Not all outliers should be removed — some contain valuable information.

🚀 Outcome

The dataset was successfully cleaned and transformed into a machine learning–ready format, improving model reliability and performance.
